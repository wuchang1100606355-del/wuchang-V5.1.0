## 📋 同步流程

1. **預覽同步計劃**（使用 `--dry-run`）
   - 掃描兩個基地端的檔案
   - 計算檔案雜湊值
   - 比較檔案差異
   - 顯示同步計劃

2. **確認同步計劃**
   - 檢查要同步的檔案列表
   - 確認同步方向（base1 = 本地）
   - 確認同步策略（newer = 較新）

3. **執行實際同步**（移除 `--dry-run`）
   - 備份現有檔案
   - 執行檔案同步
   - 生成同步報告

4. **驗證同步結果**
   - 查看同步報告
   - 檢查同步的檔案
   - 驗證檔案完整性

## ⚠️ 注意事項

1. **網絡共享認證**: 
   - 如果網絡共享需要認證，需要先輸入用戶名和密碼
   - 可以使用 `net use` 命令建立持久連接：
     ```powershell
     net use \\192.168.50.84\wuchang /user:username password /persistent:yes
     ```

2. **權限確認**:
   - 確保對兩個基地端都有讀寫權限
   - 本地需要有寫入權限

3. **備份建議**:
   - 同步前建議手動備份重要檔案
   - 工具會自動備份更新的檔案（.backup副檔名）

4. **首次同步**:
   - 首次同步可能需要較長時間（需要掃描所有檔案）
   - 建議在網絡穩定的環境下執行

5. **大檔案同步**:
   - 大檔案同步可能需要較長時間
   - 確保網絡連接穩定

**解決方法**:
