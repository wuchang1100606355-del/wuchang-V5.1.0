## 📋 已完成的配置

### 1. 核心模型

#### ✅ wuchang.router.certificate

**文件**: `wuchang_os/addons/wuchang_core/models/router_certificate.py`

**功能**:
- 證書信息存儲和管理
- 證書文件路徑管理
- 證書內容存儲（PEM 格式）
- 證書狀態追蹤（未配置/已配置/已過期/無效）
- 證書元數據（簽發者、主體、有效期）
- 使用配置（Caddy、路由器）

**主要字段**:
- `name`: 證書名稱
- `router_ip`: 路由器 IP (192.168.50.1)
- `router_model`: 路由器型號 (RT-BE86U-7428)
- `cert_file_path`: 證書文件路徑
- `key_file_path`: 私鑰文件路徑
- `certificate_content`: 證書內容 (PEM)
- `private_key_content`: 私鑰內容 (加密存儲)
- `status`: 證書狀態
- `current_ssl_method`: 當前 SSL 方法
- `valid_from` / `valid_until`: 有效期
- `use_in_caddy` / `use_in_router`: 使用配置

## 🚀 使用流程

### 1. 查看證書配置

1. 訪問: `Wuchang OS` → `基礎設施` → `路由器證書`
2. 查看默認證書配置記錄
3. 確認當前 SSL 方法為 "Caddy 自動 HTTPS"

### 2. 如果需要配置路由器證書（可選）

1. **下載證書**:
   - 訪問 `http://192.168.50.1`
   - 登入路由器管理界面
   - 進入: `系統管理` → `系統設定` → `憑證設定`
   - 下載 `cert_key.tar`

2. **解壓證書**:
   ```bash
   tar -xf cert_key.tar
   ```

3. **上傳到系統**:
   - 在 Odoo 界面打開路由器證書記錄
   - 在「證書文件」標籤頁填寫文件路徑
   - 或在「證書內容」標籤頁直接粘貼證書內容

4. **驗證證書**:
   - 點擊「驗證證書」按鈕
   - 系統會驗證證書格式和有效性

5. **應用到 Caddy**（如需要）:
   - 點擊「應用到 Caddy」按鈕
   - 重啟 Caddy 服務以應用配置
