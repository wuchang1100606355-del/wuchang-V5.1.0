## 📊 檢查內容

### DNS 檢查
- 網域：`wuchang.life`
- 檢查是否可以解析為 IP 地址

### URL 檢查
- **首頁**：
  - `https://wuchang.life/`（優先）
  - `http://wuchang.life/`（如果 HTTPS 失敗）
  
- **登入頁**：
  - `https://wuchang.life/web/login`（優先）
  - `http://wuchang.life/web/login`（如果 HTTPS 失敗）

### UI 設備通知
- 通過 HTTP POST 發送通知（如果設備運行 Web 服務）
- 創建通知文件在 `notifications/` 目錄

## 📁 生成的文件

位置：`notifications/deployment_check_{IP地址}_{時間戳}.json`

## 🔧 任務管理

### 查看任務狀態
```powershell
Get-ScheduledTask -TaskName "WuchangHourlyDeploymentCheck"
```

### 查看執行信息
```powershell
Get-ScheduledTask -TaskName "WuchangHourlyDeploymentCheck" | Get-ScheduledTaskInfo
```

### 手動觸發執行
```powershell
Start-ScheduledTask -TaskName "WuchangHourlyDeploymentCheck"
```

### 停止任務
```powershell
Stop-ScheduledTask -TaskName "WuchangHourlyDeploymentCheck"
```

### 刪除任務
```powershell
Unregister-ScheduledTask -TaskName "WuchangHourlyDeploymentCheck" -Confirm:$false
```

## ⚠️ 注意事項

1. **首次執行延遲**：定時任務設置後會延遲 60 分鐘首次執行，之後每小時執行一次
2. **權限要求**：設置定時任務需要管理員權限
3. **網絡要求**：檢查需要網絡連接，任務已設置為僅在網絡可用時執行
4. **依賴要求**：確保已安裝 `requests` 和 `urllib3` 套件
5. **日誌清理**：建議定期清理 `logs/` 和 `notifications/` 目錄中的舊文件

## 🔍 故障排除

### 問題：定時任務不執行

1. 檢查任務是否存在：
   ```powershell
   Get-ScheduledTask -TaskName "WuchangHourlyDeploymentCheck"
   ```

2. 檢查任務狀態：
   ```powershell
   Get-ScheduledTask -TaskName "WuchangHourlyDeploymentCheck" | Select-Object State
   ```

3. 檢查 Python 路徑是否正確

4. 查看任務執行歷史和錯誤信息

### 問題：檢查失敗

1. 手動執行腳本查看錯誤信息：
   ```bash
   python scripts/hourly_deployment_check.py
   ```

2. 檢查網絡連接

3. 檢查目標網域是否正常運作

4. 查看生成的報告文件了解詳細錯誤信息
