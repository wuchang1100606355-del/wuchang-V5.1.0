# wuchang_os - Odoo 自訂模組目錄

這是五常系統的 Odoo 自訂模組目錄，用於存放自訂開發的 Odoo 模組。

## 📁 目錄結構

```
wuchang_os/
└── addons/          # Odoo 自訂模組目錄
    └── .gitkeep     # 保留目錄結構
```

## 📝 說明

- **addons/** - 存放所有自訂開發的 Odoo 模組
- 模組需要遵循 Odoo 模組開發規範
- 模組名稱應使用小寫字母和下劃線

## 🔄 同步規則

根據系統同步規則：
- 雲端空間為主要資料夾區
- 找不到依賴檔案時，可從外接硬碟調用
- 寫入需兩邊寫入（同時寫入雲端空間和外接硬碟）

## 📦 使用方式

### 建立新模組

1. 在 `addons/` 目錄下建立模組資料夾
2. 建立 `__manifest__.py` 檔案
3. 建立 `__init__.py` 檔案
4. 在 Odoo 中更新應用程式清單

### 範例模組結構

```
addons/
└── my_custom_module/
    ├── __init__.py
    ├── __manifest__.py
    ├── models/
    ├── views/
    └── controllers/
```
