## 💻 伺服器配置方案

### 方案 A：全新組裝伺服器（推薦）⭐⭐⭐⭐⭐

**預算分配：** 50,000 台幣

#### 核心組件配置

**1. CPU（處理器）- 15,000-20,000 台幣**
- **推薦：** AMD Ryzen 7 7700 / 7800X
- **或：** Intel Core i7-13700 / i7-14700
- **核心數：** 8-12 核心 / 16-24 線程
- **用途：** 多容器並發、LLM 推理（CPU模式）、資料庫處理

**2. 主機板 - 6,000-8,000 台幣**
- **推薦：** AM5 平台（支援 DDR5）或 LGA1700
- **需求：** 
  - 4+ 記憶體插槽
  - 多個 PCIe 插槽（未來 GPU 擴展）
  - M.2 NVMe 插槽

**3. 記憶體（RAM）- 12,000-15,000 台幣** ⭐⭐⭐⭐⭐
- **推薦配置：** 64GB DDR5（32GB × 2）
- **用途：**
  - Odoo: 8-16GB
  - PostgreSQL: 8-16GB
  - Ollama LLM (7B): 12-16GB
  - 其他服務: 8-12GB
  - 系統: 4-8GB
- **建議：** 選擇可擴展到 128GB 的主機板

**4. 儲存（SSD）- 6,000-8,000 台幣**
- **系統盤：** 500GB-1TB NVMe SSD
  - 用途：作業系統、Docker 映像檔
- **資料盤：** 1TB-2TB NVMe SSD
  - 用途：資料庫、Odoo 資料、LLM 模型
- **備份盤：** 2TB HDD（可選）
  - 用途：備份資料

**5. 電源供應器 - 3,000-4,000 台幣**
- **推薦：** 750W-850W 80+ Gold
- **用途：** 為未來 GPU 擴展預留空間

**6. 機箱 - 2,000-3,000 台幣**
- **推薦：** 中塔式機箱，良好散熱
- **需求：** 多個風扇位，良好通風

**7. 散熱 - 1,500-2,500 台幣**
- **推薦：** 塔式 CPU 散熱器或一體式水冷
- **用途：** LLM 推理時 CPU 會產生大量熱量

**總計：** 約 46,500-60,500 台幣
**實際採購：** 可在 45,000-50,000 台幣內完成
