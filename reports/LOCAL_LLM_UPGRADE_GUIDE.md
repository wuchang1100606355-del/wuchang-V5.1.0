## 🚀 升級步驟

### 方式 1：使用自動化腳本（推薦）

**執行腳本：**
```bash
python scripts/upgrade_local_llm_model.py
```

**步驟：**
1. 腳本會檢查當前模型
2. 顯示推薦選項
3. 選擇要下載的模型
4. 自動下載和測試
5. 更新系統配置

---

### 方式 2：手動升級

**步驟 1：下載模型**
```bash
# 推薦：qwen2:7b
docker exec wuchangv510-ollama-1 ollama pull qwen2:7b

# 或 llama3.1:8b
docker exec wuchangv510-ollama-1 ollama pull llama3.1:8b
```

**步驟 2：測試模型**
```bash
docker exec wuchangv510-ollama-1 ollama run qwen2:7b "Hello, how are you?"
```

**步驟 3：更新系統配置**

**更新配置檔案：**
- `config/ai_agents/double_j_appearance.json`
- `config/ai_agents/double_j_appearance.yaml`
- `wuchang_os/addons/wuchang_core/data/system_params.xml`

**將模型名稱從 `qwen2:0.5b` 改為 `qwen2:7b`**
