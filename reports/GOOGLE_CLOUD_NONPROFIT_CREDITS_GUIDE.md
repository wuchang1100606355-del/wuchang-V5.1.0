## 🚀 開通步驟

### 步驟 1：確認 Google for Nonprofits 狀態

1. **前往 Google for Nonprofits**
   - 網址：https://www.google.com/nonprofits
   - 檢查組織驗證狀態
   - 確認已通過驗證

2. **驗證所需文件**
   - ✅ 台灣內政部立案證明
   - ✅ 組織章程
   - ✅ 最近年度財務報表
   - ✅ 稅務登記證（如適用）

### 步驟 2：申請 Google Cloud 非營利組織抵免額

1. **前往申請頁面**
   - 網址：https://cloud.google.com/apply-for-nonprofit-credits
   - 或：https://support.google.com/nonprofits/answer/10266332

2. **填寫申請表單**
   - 組織名稱：五常非營利組織
   - 組織類型：非營利組織
   - 國家/地區：台灣
   - Google Cloud 專案 ID：my-j-483304
   - 說明使用目的

3. **提交驗證文件**
   - 上傳內政部立案證明
   - 上傳組織章程
   - 上傳其他必要文件

### 步驟 3：連結帳單帳戶

1. **前往 Google Cloud Console**
   - 網址：https://console.cloud.google.com/billing?project=my-j-483304
   - 登入 Google Cloud Console

2. **設定帳單帳戶**
   - 前往：帳單 > 連結帳單帳戶
   - 建立或連結帳單帳戶
   - 選擇付款方式

3. **申請抵免額**
   - 前往：帳單 > 帳單帳戶 > 抵免額
   - 申請非營利組織抵免額
   - 提供組織驗證資訊

### 步驟 4：等待審核

- **審核時間：** 通常 7-14 個工作天
- **審核通知：** 會透過電子郵件通知
- **審核結果：** 可前往 Google Cloud Console 查看

### 步驟 5：驗證抵免額開通

1. **檢查抵免額狀態**
   - 前往：Google Cloud Console > 帳單 > 帳單帳戶
   - 查看抵免額狀態

2. **確認抵免額金額**
   - 非營利組織每月可獲得 $350 美元抵免額
   - 可用於 Google Cloud 服務

3. ✅ **Cloud SQL** - 資料庫服務
4. ✅ **Cloud Functions** - 無伺服器函數
5. ✅ **Vertex AI** - AI/ML 服務
6. ✅ **Cloud Run** - 容器服務
7. ✅ **其他 Google Cloud 服務**
