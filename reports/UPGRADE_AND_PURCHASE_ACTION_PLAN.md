# 模型升級 + 硬體採購行動計劃

## 🚀 第一步：立即升級模型（現在執行）

### 手動升級步驟

**1. 檢查 Ollama 容器狀態**
```bash
docker ps | grep ollama
```

**2. 下載 qwen2:7b 模型（推薦）**
```bash
docker exec wuchangv510-ollama-1 ollama pull qwen2:7b
```

**或下載其他模型：**
```bash
# 輕量級選項
docker exec wuchangv510-ollama-1 ollama pull qwen2:1.5b

# 其他選項
docker exec wuchangv510-ollama-1 ollama pull llama3.1:8b
docker exec wuchangv510-ollama-1 ollama pull mistral:7b
```

**3. 測試模型**
```bash
docker exec wuchangv510-ollama-1 ollama run qwen2:7b "Hello, how are you?"
```

**4. 查看已安裝的模型**
```bash
docker exec wuchangv510-ollama-1 ollama list
```

---

### 更新系統配置

**需要更新的檔案：**

1. **`config/ai_agents/double_j_appearance.json`**
   ```json
   "llm_model": {
     "local": "qwen2:7b"  // 從 qwen2:0.5b 改為 qwen2:7b
   }
   ```

2. **`config/ai_agents/double_j_appearance.yaml`**
   ```yaml
   llm_model:
     local: "qwen2:7b"  # 從 qwen2:0.5b 改為 qwen2:7b
   ```

3. **`wuchang_os/addons/wuchang_core/data/system_params.xml`**
   - 找到 `wuchang.ollama_model` 參數
   - 更新為 `qwen2:7b`

## 📦 第二步：硬體採購計劃（1-2週後）

### 觀察期（升級模型後 1-2週）

**監控項目：**
- [ ] 記憶體使用量（是否不足）
- [ ] 推理速度（是否太慢）
- [ ] 系統穩定性（是否有問題）
- [ ] 實際使用體驗

**記錄數據：**
- 記憶體峰值使用量
- 推理平均響應時間
- 系統瓶頸位置

---

### 採購決策

**根據觀察結果決定：**

#### 如果記憶體不足（使用率 > 80%）
→ **優先採購：記憶體升級到 64GB**

#### 如果推理速度慢（響應時間 > 10秒）
→ **優先採購：GPU（RTX 4060 16GB）**

#### 如果兩者都有問題
→ **先採購記憶體，再採購 GPU**

---

## 🛒 硬體採購清單

### 優先級 1：記憶體升級 ⭐⭐⭐⭐⭐

**採購項目：**
- **規格：** DDR4/DDR5 32GB × 2（共 64GB）
- **成本：** $200-$400（約 6,000-12,000 台幣）
- **品牌推薦：** Kingston, Corsair, Crucial

**採購前檢查：**
- [ ] 確認主機板型號
- [ ] 確認記憶體類型（DDR4/DDR5）
- [ ] 確認可用插槽數量
- [ ] 確認頻率匹配

**採購連結建議：**
- PChome 24h
- 原價屋
- 欣亞數位

---

### 優先級 2：GPU 加速 ⭐⭐⭐⭐⭐

**採購項目：**
- **型號：** NVIDIA RTX 4060 16GB
- **成本：** $400-$500（約 12,000-15,000 台幣）
- **品牌推薦：** ASUS, MSI, Gigabyte

**採購前檢查：**
- [ ] 確認主機板有 PCIe x16 插槽
- [ ] 確認電源供應器容量（建議 600W+）
- [ ] 確認機箱空間（長度、高度）
- [ ] 確認散熱需求

**採購連結建議：**
- 原價屋
- 欣亞數位
- PChome 24h

---

### 優先級 3：儲存優化（可選）⭐⭐⭐⭐

**採購項目：**
- **規格：** NVMe SSD 1TB-2TB PCIe 4.0
- **成本：** $100-$200（約 3,000-6,000 台幣）
- **品牌推薦：** Samsung, WD, Crucial

**採購前檢查：**
- [ ] 確認主機板有 M.2 NVMe 插槽
- [ ] 確認支援 PCIe 4.0

## 💡 重要提醒

### 模型升級注意事項

1. **記憶體需求：**
   - qwen2:7b 需要 12-16GB 記憶體
   - 如果當前只有 32GB，可能需要調整其他服務

2. **下載時間：**
   - 7B 模型約 4-5GB，下載可能需要一些時間
   - 請確保網路連線穩定

3. **測試建議：**
   - 升級後先測試簡單任務
   - 逐步測試複雜任務
   - 監控系統資源使用

---

### 硬體採購注意事項

1. **相容性檢查：**
   - 務必確認主機板相容性
   - 確認電源供應器容量
   - 確認機箱空間

2. **保固：**
   - 選擇有良好保固的品牌
   - 保留購買憑證

3. **安裝：**
   - 如果不熟悉，建議請專業人員安裝
   - 安裝前務必備份資料
