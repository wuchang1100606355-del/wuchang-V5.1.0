## 📦 模組概述

這個 Odoo 模組整合了雙J協作機制，用於管理 Google Cloud Platform 抵免額的配置和使用。

### 主要功能

- ✅ **抵免額管理** - 管理所有 GCP 抵免額
- ✅ **雙J協作** - 小J（本地）和Jules（雲端）協作配置
- ✅ **使用量追蹤** - 記錄抵免額使用情況
- ✅ **到期提醒** - 自動提醒即將到期的抵免額
- ✅ **Odoo 專案整合** - 與現有 Odoo 系統整合

## 📋 模組功能說明

### 1. 抵免額管理

**位置：** 抵免額管理 > GCP 抵免額

**功能：**
- 查看所有抵免額記錄
- 新增/編輯抵免額
- 查看使用量和剩餘額度
- 監控到期日期

**預設數據：**
模組安裝時會自動建立三個抵免額記錄：
1. **免費試用抵免額** - $8,334.55（6天後到期）
2. **Google Maps Platform** - $7,851/月（至 2027/02/01）
3. **Google Cloud 非營利** - $350/月（待審核）

---

### 2. 雙J協作配置

**使用方式：**
1. 進入抵免額表單頁面
2. 點擊「使用雙J協作配置」按鈕
3. 系統會自動建立兩個任務：
   - **小J任務**：本地處理配置
   - **Jules任務**：雲端處理配置

**協作流程：**
```
用戶點擊配置按鈕
    ↓
建立小J任務（本地）
    ↓
建立Jules任務（雲端）
    ↓
協作完成配置
```

---

### 3. 雙J協作任務管理

**位置：** 抵免額管理 > 雙J協作任務

**功能：**
- 查看所有協作任務
- 追蹤任務狀態
- 記錄執行結果

**任務狀態：**
- 待處理 (pending)
- 已分配 (assigned)
- 進行中 (in_progress)
- 已完成 (completed)
- 失敗 (failed)

## 🎯 使用範例

### 範例 1：配置免費試用抵免額

1. **進入抵免額管理**
   - 前往：抵免額管理 > GCP 抵免額

2. **選擇免費試用抵免額**
   - 點擊「免費試用抵免額」記錄

3. **啟動雙J協作**
   - 點擊「使用雙J協作配置」按鈕

4. **查看協作任務**
   - 在「雙J協作任務」頁籤中查看任務狀態

---

### 範例 2：追蹤使用量

1. **查看抵免額**
   - 在列表視圖查看「剩餘金額」欄位

2. **查看使用記錄**
   - 進入抵免額表單
   - 點擊「使用記錄」頁籤
   - 查看詳細的使用記錄

## 🔧 技術細節

**wuchang.gcp.credits（抵免額）**

## 🔍 故障排除

### 問題 1：模組無法安裝

**可能原因：**
- Odoo 容器未運行
- 模組路徑不正確
- 依賴模組缺失

**解決方法：**
```bash
# 檢查 Odoo 容器
docker ps | grep odoo

# 檢查模組路徑
ls -la wuchang_os/addons/wuchang_credits_management/

# 檢查 Odoo 日誌
docker logs wuchangv510-wuchang-web-1
```

---

**解決方法：**
1. 手動安裝數據：

   - 搜尋「wuchang.gcp.credits」
