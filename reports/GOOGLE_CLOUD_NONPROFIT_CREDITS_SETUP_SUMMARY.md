## 📋 開通流程概述

### 步驟 1：確認 Google for Nonprofits 驗證
- 前往：https://www.google.com/nonprofits
- 確認組織已通過驗證
- 準備驗證文件

### 步驟 2：申請 Google Cloud 抵免額
- 前往：https://cloud.google.com/apply-for-nonprofit-credits
- 填寫申請表單
- 提交驗證文件

### 步驟 3：連結帳單帳戶
- 前往：Google Cloud Console 帳單設定
- 建立或連結帳單帳戶
- 申請抵免額

### 步驟 4：等待審核
- 審核時間：7-14 個工作天
- 透過電子郵件接收通知

### 步驟 5：驗證抵免額開通
- 前往 Google Cloud Console 查看抵免額狀態
- 確認每月 $350 美元抵免額已生效

## 💰 抵免額資訊

- **每月抵免額：** $350 美元
- **適用服務：** 所有 Google Cloud 服務
- **使用期限：** 每月重置
- **不累積：** 當月未用完的抵免額不會累積到下個月

### 可使用抵免額的服務
- Compute Engine（虛擬機器）
- Cloud Storage（雲端儲存）
- Cloud SQL（資料庫服務）
- Cloud Functions（無伺服器函數）
- Vertex AI（AI/ML 服務）
- Cloud Run（容器服務）
- 其他 Google Cloud 服務
