# ☕ 聊國咖啡總店 - Chrome OS 終端機設定指引

## 架構說明
- **伺服器端 (Server)**: 本機容器 (liaoguo-hq)，負責運算與資料儲存。
- **終端機端 (Terminal)**: Chrome OS 設備，負責顯示操作介面。
- **關係**: 伺服器是「大腦與金庫」，Chrome OS 是「眼睛與手」。這樣設計可確保資料安全存於本機，同時利用 Chrome OS 的輕便性進行操作。

## 設定步驟

### 1. 確認連線資訊
- 請在伺服器端確認本機 IP (例如 192.168.x.x)。
- 總店系統網址為: http://<本機IP>:5001

### 2. Chrome OS 設定 (Kiosk 模式建議)
若要將 Chrome OS 設備作為專用 POS 機或展示看板，建議設定為 Kiosk 模式：

1.  登入 Google Admin 控制台 (若有管理權限)。
2.  前往 **裝置 > Chrome > 應用程式與擴充功能 > Kiosk**。
3.  新增 URL: http://<本機IP>:5001。
4.  設定為自動啟動。

### 3. 一般瀏覽器存取
若僅作為一般操作使用：
1.  將 Chrome OS 連線至與伺服器相同的 Wi-Fi 網路。
2.  開啟 Chrome 瀏覽器。
3.  輸入網址 http://<本機IP>:5001。
4.  建議將此頁面加入書籤或建立桌面捷徑。

## 為什麼這樣設計？
- **資料安全**: 私有基金 (dual_j_private_fund.json) 存放在本機加密磁區，不離開這台電腦。
- **效能穩定**: 運算由本機負責，Chrome OS 僅需負責顯示，不會卡頓。
- **維護容易**: 更新系統只需在本機操作 Docker，所有終端機自動同步更新。
