網絡狀態顯示

  • 外網訪問狀態監控
  • 連接設備統計
  • 網絡拓撲顯示

快速操作

  • 一鍵刷新系統狀態
  • 網絡設備掃描
  • 服務重啟功能
  • 緊急停止機制

命令控制台

  • 實時命令輸入和執行
  • 日誌實時輸出
  • 狀態追蹤和歷史記錄
  • 支持自定義命令

技術架構

前端技術

  • HTML5 - 結構標記
  • CSS3 - 終端風格設計（綠色主題、掃描線動畫）
  • JavaScript - 動態交互和 API 調用
  • Bootstrap 5 - 響應式框架
  • Bootstrap Icons - 圖標庫

後端服務

  • Caddy - 反向代理和靜態文件服務
  • Cloudflare Tunnel - 外網訪問通道
  • Docker Compose - 容器編排
架構流程： 用戶 → Cloudflare Tunnel → Caddy (80/443) → 指揮通道 UI ↓ Odoo/Ollama/DB (狀態檢查)
