# 五常社區服務系統深度研究與設計規劃報告

## 1. 系統現狀分析 (System Analysis)

### 1.1 系統架構 (Architecture)
本系統「五常社區服務系統 V5.1.0」採用分層式微服務架構，核心組件包括：
-   **基礎設施層**: 基於 ASUS RT-BE86U 路由器的網路管理，實現設備納管與流量控制。
-   **數據層**: PostgreSQL 資料庫存儲社區與 Odoo 業務數據；本地文件系統存儲非結構化資料。
-   **業務邏輯層**: 基於 Odoo 18 的 13 個核心模組（物業、商業、照護、志工、競選等）。
-   **API 服務層**: FastAPI 提供雙角色（店家/架構師）API，整合 Odoo 與 AI 服務。
-   **AI 智慧層**: 「小j (Little J)」雙角色智慧核心，整合本地 Ollama 與雲端 Vertex AI，具備 STT/TTS 語音交互能力。
-   **前端介面層**: 目前混雜多種介面（Web Portal, POS, 靜態 HTML），缺乏統一的設計語言與使用者流程。

### 1.2 技術堆疊 (Tech Stack)
-   **Backend**: Python (FastAPI, Odoo), Docker
-   **Frontend Potential**: React, Tailwind CSS, Vite (依據 package.json 配置)
-   **AI**: Ollama (Local), Vertex AI (Cloud)
-   **Database**: PostgreSQL

### 1.3 當前痛點 (Pain Points)
-   **介面不統一**: 存在多個獨立的 HTML 檔案與不同的 UI 風格，缺乏一致的品牌識別。
-   **使用者流程斷裂**: 各模組間的切換可能不夠流暢。
-   **AI 感性連結不足**: 雖然功能強大，但缺乏與居民的情感連結與「公益」訴求的視覺呈現。

## 2. 網站設計標準 (Design Standards)

### 2.1 設計風格：寫實公益風 (Realistic Public Welfare Style)
本設計將強調真實感、溫暖與信任，避免過度抽象或卡通化的元素。

-   **視覺語言 (Visual Language)**:
    -   **真實影像**: 大量使用社區真實場景、居民互動的高畫質照片（需處理隱私或使用寫實風格生成的示意圖）。
    -   **色彩計畫**:
        -   *主色*: **大地暖色調** (Warm Earth Tones) - 象徵土地與社區的溫度 (e.g., #8B4513 暖褐, #D2691E 陶土色)。
        -   *輔助色*: **生機綠** (Vitality Green) - 象徵永續與成長 (e.g., #2E8B57 海洋綠)。
        -   *強調色*: **科技藍** (Tech Blue) - 象徵 AI 小j 的智慧守護 (e.g., #4682B4 鋼青色)，但需低調處理，融合於自然色調中。
    -   **字體**: 使用清晰、人文感強的黑體（如 Noto Sans TC），標題可採用具備手寫感或厚重感的字體以增加人情味。

### 2.2 使用者體驗 (UX) 原則
-   **以人為本**: 所有功能入口需以「居民需求」為導向，而非「系統模組」導向。
-   **情感化交互**: 在與小j 互動時，強調「對話」與「傾聽」，而非單純的指令輸入。
-   **無障礙設計 (Accessibility)**: 考量社區長者需求，字體需夠大，對比度需足夠，操作需直觀。

## 3. 首頁設計方案 (Homepage Design Plan)

### 3.1 核心概念：數位 AI 社區守護者
首頁將作為「全社區共同培育 AI」的入口。

### 3.2 頁面結構
1.  **Hero Section (感性呼籲區)**:
    -   **背景**: 寫實風格的社區全景或溫馨生活照（動態輪播）。
    -   **文案**: 「小j，我們的數位家人。今天，你跟她說夢想了嗎？」
    -   **核心行動 (CTA)**: 「與小j 聊聊夢想」 (啟動語音/文字對話)。

2.  **AI 公益價值區 (AI for Public Welfare)**:
    -   展示 AI 如何協助獨居長者、優化社區資源、守護社區安全。
    -   強調「AI 公益化」：AI 不只是工具，而是促進社會公平與關懷的媒介。

3.  **小j 教育工作站 (Little J Education Station)**:
    -   **互動區**: "Feed Little J with Dreams"。
    -   **機制**: 居民輸入對社區的願景（如：更乾淨的街道、更多的長者活動），小j 即時回饋這些夢想如何被轉化為系統參數或學習目標。
    -   **成長條**: 顯示小j 透過居民互動獲得的「守護值」或「智慧等級」。

4.  **服務導覽 (Service Navigation)**:
    -   以卡片式設計整合物業、商業、照護等功能，保持統一的寫實風格圖標。

## 4. 執行計畫 (Execution Plan)
1.  **初始化前端專案**: 建立基於 React + Vite + Tailwind 的專案結構。
2.  **建置設計系統**: 設定 Tailwind 主題配置 (Colors, Typography)。
3.  **開發首頁組件**: 實作 Hero, AI Value, Dream Chat 等區塊。
4.  **整合 AI 介面**: 模擬或串接小j 的對話 API。
5.  **全站套用**: 將設計標準推廣至其他頁面。
