# 客顯設備網路故障排除指南

**文件日期**: 2025-01-07  
**系統版本**: Wuchang OS V5.1.0  
**目標**: 解決客顯設備無法上網的問題

---

## 🔍 診斷步驟

### 1. 檢查本機網路狀態

執行以下 PowerShell 腳本進行完整診斷：

```powershell
cd "C:\wuchang V5.1.0"
.\scripts\diagnose_customer_display_network.ps1 -CustomerDisplayIP "192.168.50.XXX"
```

（將 `192.168.50.XXX` 替換為客顯設備的實際 IP 地址）

### 2. 檢查客顯設備的網路設定

#### Chrome OS 客顯設備

1. **檢查 Wi-Fi 連線**：
   - 在客顯設備上打開設定
   - 確認已連接到正確的 Wi-Fi 網路（SSID: `coova.org` 或對應的網路）
   - 檢查 Wi-Fi 訊號強度

2. **檢查 IP 設定**：
   - 確認設備 IP 在 `192.168.50.x` 網段
   - 確認子網路遮罩為 `255.255.255.0`
   - 確認預設閘道為 `192.168.50.1`

3. **檢查 DNS 設定**：
   - 確認 DNS 伺服器為 `192.168.50.1` 或 `8.8.8.8`

### 3. 常見問題與解決方案

#### 問題 1: 客顯設備無法連接到 Wi-Fi

**可能原因**：
- Wi-Fi 密碼錯誤
- Wi-Fi 訊號太弱
- 路由器 MAC 地址過濾

**解決方案**：
1. 重新輸入 Wi-Fi 密碼
2. 將設備移近路由器
3. 檢查路由器設定，確認未啟用 MAC 地址過濾，或將客顯設備的 MAC 地址加入允許清單

#### 問題 2: 客顯設備可以連接到 Wi-Fi，但無法上網

**可能原因**：
- DNS 設定錯誤
- 路由器未提供 DHCP 服務
- 防火牆阻擋

**解決方案**：
1. 手動設定 DNS 伺服器為 `8.8.8.8` 和 `8.8.4.4`
2. 檢查路由器 DHCP 設定
3. 檢查路由器防火牆規則，確認未阻擋客顯設備

#### 問題 3: 客顯設備無法連接到 Odoo 伺服器

**可能原因**：
- Odoo 服務未運行
- 防火牆阻擋連接埠 8069
- IP 地址不正確

**解決方案**：
1. 確認 VM 伺服器 (192.168.50.249) 的 Odoo 服務正在運行
2. 檢查防火牆設定，確認連接埠 8069 已開放
3. 確認客顯設備使用的 URL 正確：`http://192.168.50.249:8069/pos/customer_display`

### 4. 重新註冊客顯設備

如果以上步驟都無法解決問題，可以嘗試重新註冊客顯設備：

```powershell
cd "C:\wuchang V5.1.0"
python scripts\enroll_chrome_os_customer_display.py
```

或使用 PowerShell 腳本：

```powershell
cd "C:\wuchang V5.1.0"
.\scripts\enroll_all_devices.ps1
```

### 5. 檢查設備狀態

透過 Odoo 後台檢查設備狀態：

1. 登入 Odoo：`http://192.168.50.249:8069/web/login`
2. 導航至「基礎設施」→「設備管理」
3. 搜尋客顯設備（設備類型：Chrome OS）
4. 檢查設備狀態和最後連線時間
5. 點擊「檢查狀態」按鈕更新設備狀態

### 6. 網路連線測試

在客顯設備上執行以下測試：

1. **測試本地連線**：
   - 打開瀏覽器，訪問 `http://192.168.50.249:8069`
   - 如果無法訪問，檢查 IP 地址和連接埠

2. **測試外部連線**：
   - 打開瀏覽器，訪問 `http://www.google.com`
   - 如果無法訪問，檢查 DNS 設定和路由器連線

3. **測試 Odoo 服務**：
   - 訪問 `http://192.168.50.249:8069/pos/customer_display`
   - 確認可以正常顯示客顯介面

## 💡 建議

1. **檢查客顯設備的實際 IP 地址**：
   - 在客顯設備上查看網路設定
   - 或透過路由器管理介面查看已連接設備列表

2. **確認客顯設備與 VM 伺服器在同一網段**：
   - VM 伺服器：192.168.50.249
   - 客顯設備應在：192.168.50.x

3. **檢查路由器設定**：
   - 確認路由器未對客顯設備進行網路限制
   - 確認路由器 DHCP 服務正常運行

4. **重新啟動設備**：
   - 重啟客顯設備
   - 重啟路由器（如需要）
