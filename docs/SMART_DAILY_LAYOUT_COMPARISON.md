# 智生活 (Smart Daily) 版面學習與深度比對報告

## 1. 智生活 (Smart Daily) 版面分析

智生活採用 **Mobile-First (行動優先)** 的設計哲學，強調住戶在手機上的單手操作與資訊速覽。

### 1.1 首頁儀表板 (Home Dashboard)
- **版面結構**:
  - **頂部資訊卡**: 顯示社區名稱、戶號、當前管理費餘額/未繳金額。
  - **快捷功能區 (Grid Icon Layout)**: 核心功能以 3x3 或 4x2 圖示網格排列。
    - **高頻功能**: 公告、包裹、繳費、報修。
    - **生活服務**: 預約、團購、意見箱。
  - **動態資訊流 (Feed)**: 下方顯示最新公告摘要、未領包裹提示。
- **特點**:
  - **直覺導航**: 使用者無需進入層層選單，核心需求在首頁一鍵觸達。
  - **紅點通知**: 在圖示右上角顯示未讀數 (Badges)，如「包裹 (2)」、「公告 (1)」。

### 1.2 底部導航列 (Bottom Navigation)
通常包含 4-5 個標籤：
1. **首頁 (Home)**: 儀表板。
2. **服務 (Services)**: 生活服務、預約、團購商城。
3. **訊息 (Messages)**: 個人通知、社區公告歷史。
4. **我的 (Me/Profile)**: 戶號切換、個人設定、與我們聯絡。

### 1.3 互動體驗 (UX)
- **卡片式設計 (Card UI)**: 資訊以卡片呈現，邊界清晰。
- **大按鈕與大字體**: 考量全年齡層住戶 (含長者)。
- **流程簡化**: 報修僅需「拍照 -> 選類別 -> 說明 -> 送出」四步驟。

## 2. 五常系統 (Wuchang OS) 現況分析

五常系統基於 Odoo 架構，目前主要呈現 **Web-Backend (後台管理)** 風格。

### 2.1 現有版面結構
- **桌機版 (Desktop)**:
  - 左側/頂部導航選單 (Sidebar/Navbar)。
  - 標準列表視圖 (List View) 與表單視圖 (Form View)。
  - 適合物業經理與管委會進行複雜資料管理。
- **行動版 (Mobile Web)**:
  - Odoo 響應式網頁 (Responsive)。
  - 漢堡選單 (Hamburger Menu) 收納所有模組。
  - 對一般住戶而言，操作路徑較長 (例如：點選單 -> 物業管理 -> 報修 -> 新增)。

### 2.2 落差分析 (Gap Analysis)

| 比較項目 | 智生活 (Smart Daily) | 五常系統 (Wuchang OS) | 體驗落差 |
| :--- | :--- | :--- | :--- |
| **首頁入口** | 圖示網格 (Grid Icons) | 模組列表/看板 (Apps Menu) | 五常系統缺乏「住戶專屬」的簡易入口。 |
| **通知呈現** | 圖示紅點 (Badges) | 討論區/信箱 (Mail/Discuss) | Odoo 通知較偏向企業內部溝通，非 B2C 推播風格。 |
| **報修流程** | 4 步驟精簡引導 | 標準表單填寫 | Odoo 表單欄位多，對手機操作負擔較大。 |
| **導航模式** | 底部標籤 (Bottom Nav) | 漢堡選單 (Hamburger) | 漢堡選單隱藏了功能，降低探索率與使用頻率。 |

## 3. 深度比對與改善建議

為縮小與智生活的體驗落差，建議五常系統進行以下版面優化：

### 3.1 建立「住戶專屬入口 (Resident Portal)」
不應直接讓住戶進入 Odoo 後台，而是開發一個基於 **Odoo Website** 的客製化頁面 (Portal)。

- **建議實作**:
  - 使用 Odoo QWeb 引擎建立 `/resident/home` 頁面。
  - **Layout**: 仿照智生活，實作 CSS Grid 版面。
  - **Components**:
    - `<div class="shortcut-grid">`: 包裹、公告、報修圖示。
    - `<div class="status-card">`: 顯示待繳管理費、未領包裹數。

### 3.2 流程優化 (以報修為例)
- **智生活**: 拍照優先。
- **五常改善**:
  - 開發 Mobile-First 的報修 Wizard (精靈模式)。
  - 第一步直接呼叫 `<input type="file" capture="camera">`。
  - 自動帶入戶號與聯絡人 (從登入資訊讀取)。

### 3.3 視覺識別 (Visual Identity)
- **智生活**: 溫馨、明亮、社區感。
- **五常改善**:
  - 調整配色，從標準 Odoo 紫/灰色系，轉為更具親和力的暖色系。
  - 引入 Icon Set (如 FontAwesome 或 Material Icons) 替換文字連結。

## 4. 結論
五常系統功能面已逐漸齊備 (報修、Google 整合)，但**介面 (UI)** 與 **體驗 (UX)** 仍停留在 B2B 系統思維。
下一步關鍵在於 **「Headless」或「Portal Customization」**：在 Odoo 強大的後端之上，蓋一層類似智生活的輕量級前端 (或高度客製化的 Website 頁面)，以滿足住戶對「簡單、直覺」的需求。
