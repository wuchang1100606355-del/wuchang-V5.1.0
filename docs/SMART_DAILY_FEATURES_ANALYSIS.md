# 智生活 (Smart Daily) 功能分析報告

## 1. 簡介
本文件整理「智生活 (Smart Daily)」社區管理系統之主要功能，作為五常物業系統 (Wuchang Property Toolkits) 開發與功能補全之參考基準。

## 2. 核心功能列表

### 2.1 行政與管理 (Administration)
- **公告系統 (Announcements)**
    - 社區公告發布 (推播通知)
    - 分類公告 (一般、緊急、會議記錄)
    - 已讀/未讀統計
- **包裹與郵務 (Parcels & Mail)**
    - 包裹掛號登記 (條碼/OCR 辨識)
    - 住戶領取通知 (App 推播)
    - 智慧櫃整合 (Smart Cabinet) - 24H 自助領取
- **管理費 (Management Fees)**
    - 帳單產生與推播
    - 多元繳費串接 (超商、ATM、信用卡)
    - 財務報表與對帳功能
- **區權會與投票 (Voting & Meetings)**
    - 線上投票 (表決議案)
    - 區權會簽到 (QR Code)
    - 會議資料/議程檢視

### 2.2 住戶服務 (Resident Services)
- **公設預約 (Facility Booking)**
    - 預約時段查詢與登記 (健身房、KTV 等)
    - 點數/扣點機制
- **報修系統 (Maintenance Requests)**
    - 住戶 App 提交報修 (附照片)
    - 管理端派工與進度追蹤
    - 完工回報與評價
- **意見反映 (Feedback/Opinion Box)**
    - 住戶意見投遞
    - 管委會/物業回覆機制

### 2.3 門禁與安全 (Access & Security)
- **訪客管理 (Visitor Management)**
    - 訪客預約 (產生 QR Code 通行證)
    - 訪客到訪通知
- **雲端對講機 (Cloud Intercom)**
    - 手機 App 取代傳統室內機
    - 影像對講與遠端開門

### 2.4 生活加值 (Life Services)
- **生活服務**
    - 居家清潔、家電清洗預約
    - 叫車服務
- **團購/商城**
    - 社區團購活動

## 3. 五常系統 (Wuchang OS) 對照分析

| 功能項目 | 智生活 (Smart Daily) | 五常系統 (Wuchang OS) | 狀態/建議 |
| :--- | :--- | :--- | :--- |
| **報修管理** | 完整 (申請->派工->結案) | 已實作基礎流程 (Draft->Done) | ✅ 需補強前端表單與照片上傳 |
| **包裹通知** | 完整 (含智慧櫃) | 尚無 | ⚠️ 建議列為下一階段開發重點 |
| **公設預約** | 完整 (含點數) | 尚無 | ⚠️ 建議新增 Facility Booking 模組 |
| **管理費** | 完整 (金流串接) | `wuchang_finance` | 🔄 需整合至住戶前端介面 |
| **公告** | 完整 | 基礎 CMS 功能 | 🔄 需強化推播與分類 |
| **投票** | 完整 | 尚無 | ⚪ 視需求開發 |
| **雲端對講** | 完整 | 尚無 | ⚪ 硬體相依性高，暫不列入優先 |

## 4. 結論
五常系統目前在「報修管理」已建立基礎，但在「包裹管理」與「公設預約」方面仍有缺口。建議優先開發這兩項高頻率使用的功能，以提升住戶黏著度。
