# 五常物業系統 - 門市與一般工作人員使用說明書

## 1. 角色定義
本手冊專為 **門市人員 (POS 操作員)** 與 **一般社工/行政人員** 編寫。
您是五常社區運作的第一線天使，負責執行具體的服務任務與業務操作。

## 2. 核心功能與入口

### 2.1 POS 管理 (Point of Sale)
- **位置**：主選單 > POS 管理
- **適用角色**：門市人員
- **功能**：
    - **POS 系統**：啟動前台銷售介面，進行點餐與結帳。
    - **費用支出**：登記門市日常營運的小額支出 (如採買耗材)。

### 2.2 任務管理 (Tasks)
- **位置**：主選單 > 任務管理
- **適用角色**：全體工作人員
- **功能**：
    - **我的任務**：查看指派給您的工作項目。
    - **線上訂單**：處理來自網站或 App 的服務預約與訂單。

### 2.3 語音協助 (Voice Assist)
- **位置**：主選單 > 五常社區 > 最高指揮倉 > 語音對話
- **功能**：
    - 若操作遇到困難，或需要查詢資料，可直接在此輸入或語音詢問 AI 助理。

## 3. 日常作業流程
1. **上班打卡**：(若系統有啟用考勤模組) 進行簽到。
2. **開啟 POS**：門市人員請開啟 POS 機台，準備營業。
3. **任務確認**：社工人員請進入「任務管理」，確認今日訪視或服務對象。
4. **報表填寫**：下班前請確認當日「營業報表」或「服務紀錄」已完成歸檔。

## 4. 問題回報
若系統操作不順，或 POS 機台發生故障，請立即通知店長，或透過「語音對話」功能留言回報給系統管理員。
