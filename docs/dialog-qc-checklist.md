# 對話品質標準化檢查表

## 對話完整性評估指標
- 任務與步驟列舉完整度
- 關鍵需求是否具體化
- 風險與限制是否被提及
- 驗證與交付是否定義

## 語意連貫性檢測標準
- 無矛盾陳述與衝突指令
- 段落之間銜接自然
- 名詞與指稱一致
- 重要術語定義一致

## 意圖達成率衡量基準
- 明確目標存在
- 可度量完成條件
- 明確執行者與資源
- 完成進度與成果陳述

## 動態分配與補救機制
- 依複雜度設定監控頻率
- 長時間未回應觸發補救
- 多次未完成項提升優先級
- 出現矛盾時啟動一致性修補

## 多層級品質驗證
- 即時語義分析
- 上下文一致性檢查
- 意圖達成度評估

## 報表與持續改進
- 缺失項目統計
- 流程優化建議
- 異常模式分析
- 迭代追蹤與回饋循環
