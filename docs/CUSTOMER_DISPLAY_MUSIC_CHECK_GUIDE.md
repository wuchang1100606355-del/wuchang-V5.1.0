# 客顯設備音樂播放檢查機制使用指南

**文件日期**: 2025-01-07  
**系統版本**: Wuchang OS V5.1.0  
**核心原則**: **人為設定優先於自動檢測**

---

## 🎯 核心設計原則

### 優先級順序

1. **人為設定（最高優先級）**
   - 手動指定的播放清單
   - 手動指定的單曲
   - 管理員明確設定的音樂來源

2. **自動檢測（僅在未手動設定時使用）**
   - 僅監控當前播放狀態
   - 比對是否符合台灣咖啡館常用音樂
   - 不主動干預播放

3. **停用檢查**
   - 完全停用音樂播放檢查功能

---

## 📋 功能說明

### 1. 音樂播放清單管理

**位置**: 基礎設施 → 客顯音樂管理 → 音樂播放清單

**功能**:
- 建立和管理台灣咖啡館常用音樂清單
- 設定音樂類型、藝術家、來源等資訊
- 標記音樂是否適合台灣咖啡館
- 設定適用性評分（1-10 分）

**預設清單包含**:
- 爵士樂：Take Five、Autumn Leaves
- Bossa Nova：The Girl from Ipanema、Corcovado
- 台灣獨立音樂：島嶼天光、日常
- 輕音樂：River Flows in You、Comptine d'un autre été
- Lounge 音樂：Café del Mar
- 環境音樂：Ambient Works

### 2. 設備音樂設定（人為設定優先）

**位置**: 基礎設施 → 客顯音樂管理 → 設備音樂設定

**設定類型**:

#### 2.1 手動指定播放清單（推薦）
- **優先級**: 最高
- **說明**: 管理員手動選擇適合的播放清單項目
- **使用場景**: 確保播放特定類型的音樂

#### 2.2 手動指定單曲
- **優先級**: 高
- **說明**: 管理員手動指定單一曲目
- **使用場景**: 播放特定歌曲或藝術家

#### 2.3 自動檢測（僅監控）
- **優先級**: 低
- **說明**: 僅監控當前播放狀態，不主動干預
- **使用場景**: 了解當前播放情況，但不強制播放特定音樂

#### 2.4 停用音樂檢查
- **說明**: 完全停用音樂播放檢查功能

**設定步驟**:
1. 選擇客顯設備
2. 選擇設定類型（建議選擇「手動指定播放清單」）
3. 如果選擇「手動指定播放清單」，從清單中選擇適合的音樂項目
4. 設定優先級（人為設定建議設為 10）
5. 點擊「套用設定」

### 3. 音樂檢查記錄

**位置**: 基礎設施 → 客顯音樂管理 → 檢查記錄

**功能**:
- 記錄每次音樂播放檢查的結果
- 顯示是否符合人為設定
- 顯示是否適合台灣咖啡館
- 提供符合度報告

**檢查來源**:
- **手動檢查**: 管理員手動觸發的檢查
- **自動檢測**: 系統自動執行的檢查（僅在啟用自動檢測時）
- **設備主動回報**: 設備端主動回報的播放狀態

## 🔧 API 使用說明

### 1. 設備端回報音樂播放狀態

**端點**: `POST /api/customer_display/music/check`

**請求格式**:
```json
{
    "device_id": 123,
    "track_name": "Take Five",
    "artist": "Dave Brubeck Quartet",
    "source": "spotify",
    "is_playing": true,
    "volume": 50,
    "audio_quality": "good"
}
```

**回應格式**:
```json
{
    "status": "success",
    "check_id": 456,
    "matches_manual_config": true,
    "is_appropriate": true,
    "match_confidence": 0.9,
    "message": "人為設定優先：符合"
}
```

### 2. 獲取設備音樂設定

**端點**: `GET /api/customer_display/music/config?device_id=123`

**回應格式**:
```json
{
    "status": "success",
    "config": {
        "config_type": "manual_playlist",
        "is_active": true,
        "priority": 10,
        "playlist": [
            {
                "id": 1,
                "name": "Take Five",
                "artist": "Dave Brubeck Quartet",
                "genre": "jazz",
                "source_url": "spotify:track:...",
                "source_id": "..."
            }
        ],
        "message": "人為設定優先"
    }
}
```

### 3. 獲取符合度報告

**端點**: `GET /api/customer_display/music/compliance?device_id=123&days=7`

**回應格式**:
```json
{
    "status": "success",
    "report": {
        "total_checks": 100,
        "manual_config_matched": 95,
        "manual_config_not_matched": 3,
        "no_manual_config": 2,
        "compliance_rate": 95.0,
        "message": "人為設定符合率：95/100 (95.0%)"
    }
}
```

## 💡 使用建議

### 1. 初始設定

1. **建立音樂播放清單**:
   - 進入「音樂播放清單」
   - 新增適合台灣咖啡館的音樂項目
   - 設定適用性評分

2. **為客顯設備設定音樂配置**:
   - 進入「設備音樂設定」
   - 選擇客顯設備
   - 選擇「手動指定播放清單」
   - 從清單中選擇適合的音樂項目
   - 設定優先級為 10（最高）
   - 點擊「套用設定」

### 2. 日常監控

1. **查看檢查記錄**:
   - 進入「檢查記錄」
   - 查看是否符合人為設定
   - 查看是否符合台灣咖啡館風格

2. **查看符合度報告**:
   - 透過 API 或後台查看符合度報告
   - 了解音樂播放的符合率

### 3. 調整設定

如果發現播放的音樂不符合設定：

1. **檢查設備設定**:
   - 確認設備的音樂設定是否正確
   - 確認優先級是否正確

2. **更新播放清單**:
   - 如果需要的音樂不在清單中，新增到播放清單
   - 更新設備的音樂設定

3. **重新套用設定**:
   - 點擊「套用設定」按鈕
   - 確認設定已生效

## 🎵 台灣咖啡館常用音樂類型

### 推薦音樂類型

1. **爵士樂 (Jazz)**
   - 適合營造輕鬆、優雅的氛圍
   - 推薦：Take Five、Autumn Leaves

2. **Bossa Nova**
   - 適合營造溫暖、舒適的氛圍
   - 推薦：The Girl from Ipanema、Corcovado

3. **輕音樂/原聲 (Acoustic)**
   - 適合營造安靜、專注的氛圍
   - 推薦：River Flows in You、Comptine d'un autre été

4. **台灣獨立音樂**
   - 適合營造在地、親切的氛圍
   - 推薦：島嶼天光、日常

5. **Lounge 音樂**
   - 適合營造現代、時尚的氛圍
   - 推薦：Café del Mar

6. **環境音樂 (Ambient)**
   - 適合營造平靜、放鬆的氛圍
   - 推薦：Brian Eno 的作品
