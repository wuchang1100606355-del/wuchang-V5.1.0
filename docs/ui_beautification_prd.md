# 前後台響應式美化專案 PRD

## 目標
- 建立一致、美觀、易讀、可維護的前後台 UI 規範
- 全面響應式，優化行動與桌面體驗
- 不影響現有功能與路由，漸進式導入

## 設計令牌（Design Tokens）
- 色彩：主色、輔色、成功、警告、危險、背景、邊框
- 字體：字族、字重、字級（12/14/16/18/20/24/32）
- 間距：4/8/12/16/24/32 px 尺度
- 圓角：4/8/12 px
- 陰影：低/中/高層級

## 斷點與響應策略
- xs: 0–575、sm: 576–767、md: 768–991、lg: 992–1199、xl: 1200+
- 行動優先：小螢幕一欄，桌面多欄；表格可橫向捲動
- 觸控優化：按鈕間距 ≥ 44px、表單輸入放大

## 元件與版型
- 導覽列、面包屑、側欄、卡片、表單、表格、按鈕、徽章、提示、模態窗
- 列表頁：搜尋/過濾固定區、表格捲動容器、回到頂部
- 詳細頁：雙欄佈局（主內容 + 側資訊）

## 互動與動畫
- 微互動（hover、focus、active）統一；動畫 ≤ 200ms，避免昂貴陰影

## 效能與相容
- 關鍵 CSS 內聯（首屏）、延遲載入次要樣式、圖片壓縮
- 相容 Chrome/Edge/Firefox；Polyfill 最小化

## 交付物
- 設計令牌 CSS 變數檔
- 元件樣式與範例頁
- 指南文件與用法示例

## 限制
- 不引入大型框架；優先純 CSS，漸進增強
- 保留 Odoo 現有視圖與 QWeb 結構
