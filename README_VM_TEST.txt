[時空黑科技極限效能測試指南]

1. 安裝環境:
   請確保 VM 已安裝 Python (建議 3.9+)。
   若為純淨環境，請執行 install_spacetime_expansion.ps1 進行部署。

2. 執行測試:
   在終端機 (PowerShell 或 CMD) 中執行:
   python run_vm_test_suite.py

3. 查看報告:
   程式執行完畢後，會自動生成並開啟:
   public_html/SPACETIME_VS_LEGACY_DASHBOARD.html

   此儀表板包含:
   - 效能倍增率 (Speedup)
   - IOPS 對決
   - 資源效率分析圖表
