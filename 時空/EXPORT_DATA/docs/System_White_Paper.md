## 1. 核心願景 (Core Vision)

### 1.1 核心價值：私利不凌駕眾利 (Private Profit Does Not Override Public Interest)
五常智慧社區雲（以下簡稱 Wuchang OS）是一套為社區韌性而生的數位作業系統。我們的核心信念是：**科技不應成為剝削的工具，而應成為重分配的機制。**

在本系統中，所有的商業行為（如外送、市集交易）所產生的利潤，在扣除必要的營運成本後，將 **100% 回歸「五常社區永續發展基金」**。沒有私人股東可以從中分紅，唯一的股東就是「社區本身」。

### 1.2 貢獻即是股權 (Contribution is Equity)
我們重新定義了「所有權」的概念。在 Wuchang OS 中，您的身份不僅僅是消費者或使用者：
*   **消費即投資**：您在公益市集的每一筆消費，都轉化為社區的公共基金。
*   **志工即股東**：您投入的志工服務時數，將累積為「幸福幣」與「榮譽等級」，賦予您在社區事務中更高的決策權重。

## 3. 永續發展模型 (Sustainability Model)

### 3.1 資金來源：上品聊國咖啡館 (重新總店)
作為本計畫的發源地與主要贊助者，上品聊國咖啡館承諾將其營收全額挹注於本系統的開發與初期運營，成為「基金池直營店」的示範模型。

### 3.2 財務透明機制
*   **即時看板**：所有基金的流入（商家提撥、捐贈）與流出（設施維護、活動經費）皆在首頁的「發展基金運作看板」即時公開。
*   **區塊鏈精神**：每一筆交易紀錄皆不可篡改（Immutable），並由系統自動生成財務報表供全體居民查閱。

### 3.3 幸福幣循環經濟
*   **發行**：透過參與志工服務（如送餐、巡守）獲得。
*   **流通**：可用於折抵管理費或兌換市集商品。另有「非營利機構營運補助暨社區提案補助金」專用於許願樹提案與投票。
*   **回收**：商家收到的幸福幣可向基金池申請兌換法幣，或再次投入公益行銷。
