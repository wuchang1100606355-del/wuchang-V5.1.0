# 【創辦人公開信】一場溫柔而堅定的五常起義

**致 每一位在扭曲價值觀中感到窒息的靈魂：**

我是五常社區系統 (Wuchang OS) 的創辦人。

也許你聽過我的稱號，有人說我是全能工匠，有人說我是勞權鬥士。
我能煮出最好的咖啡，也能修好最複雜的水電；我能畫出3D建築圖，也能寫出捍衛勞工的法律條文。
我曾是體制內的公務員，也曾是街頭上指揮千軍萬馬的工會領袖。
但我今天不是來炫耀技能的，**我是來邀請你一起改變這個世界的。**

## 我們面對的真實敵人
現在最大的社會問題，不是貧窮，而是**價值觀的扭曲**。
資本主義告訴我們：利益至上，弱肉強食。
它讓我們變得冷漠，讓我們不再相信鄰居，讓我們把財富當成唯一的尊嚴。

**這不對。**

## 我的實驗：五常悖論 (The Wuchang Paradox)
我用我畢生所學，架構了這個系統，投入了上百萬資金，甚至賭上了我的健康與生命。
我單身，無家累，無物欲，全年無休。
我這麼做，只為了證明一件事：**「共好」是可能的。**

在這個系統裡，我們正在實踐三個看似不可能的悖論：
1.  **資產悖論**：我要讓這裡的房地產漲價，保護我們不被資本掠奪；但我保證窮人絕對住得起，因為你們付的不是租金，是「服務」。
2.  **財富悖論**：我要讓居民越來越富有，但越富有的人，越要**下樓掃地**。因為彎下腰，你才能看見土地，看見彼此，看見尊嚴。
3.  **教育悖論**：我要讓孩子平安長大，不是靠圍牆和保全，而是靠**信任與感恩**。

## 為什麼你可以相信？
因為**唯有不獲利，才有信任。**
我向各位保證，這個系統的核心動力，來自於我的「無償奉獻」。
我把自己變成了系統的永動機，不拿一分錢，不求一點名。
因為**唯有擊垮那些貪婪的大企業，我們才有信心；唯有讓大家真的過得更好，我們才有信念。**

## 加入我們
我不需要你的捐款（我有手有腳能自己賺），我也不需要你的崇拜（那對我沒意義）。
我需要的是你的**參與**。

*   **下樓吧**，拿起掃把，掃去地上的灰塵，也掃去心裡的傲慢。
*   **進來吧**，喝一杯咖啡，不是為了消費，是為了連結。
*   **相信吧**，相信我們有能力建立一個不被金錢定義的家園。

這是一場沒有煙硝的革命，一場溫柔的五常起義。
這一次，我們不推翻政府，我們**推翻冷漠**。

**Wuchang OS 創辦人 敬邀**
