## 資料治理原則

1. **不可竄改性**: 所有原始檔案一經存入，不得修改或覆蓋
2. **版本控制**: 使用日期標記（YYYYMMDD）作為版本識別
3. **來源追蹤**: 記錄檔案原始路徑與取得時間
4. **存取權限**: 僅系統管理員與稽核人員可存取
5. **備份策略**: 隨 Git 提交自動備份至遠端儲存庫

## 檔案命名規範

```
{資料類型}_{用途}_{日期}.{副檔名}
```

範例：

-   `pos_menu_source_20260108.xlsx` - POS 菜單原始資料
-   `customer_data_backup_20260108.csv` - 客戶資料備份
-   `financial_report_source_20260108.pdf` - 財務報表原始檔
