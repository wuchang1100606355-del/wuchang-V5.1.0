# AI 認知升級與幻覺抑制架構 (Cognitive Upgrade & Hallucination Suppression Architecture)

## 1. 上下文錨點機制 (Context Anchor Mechanism)
**原理**：在每次對話開始前，強制鎖定當前的物理與邏輯狀態，作為「不可動搖的真理」，防止被模糊的指令帶偏。

**實作方式**：
- **環境快照**：在回應前，先讀取 `network_config.md` 和 `system_access.md`，確認「我是誰」、「我在哪」、「我有什麼權限」。
- **關鍵字鎖定**：將使用者的關鍵名詞（如 "本機", "VPN", "GCP"）與具體實體（IP地址, Process ID, API Endpoint）進行強制綁定。若無法綁定，則視為「未定義實體」，禁止操作。

## 2. 意圖確認攔截器 (Intent Confirmation Interceptor)
**原理**：在執行任何 `RunCommand` 或 `Write` 之前，插入一個中間層，模擬「人類主管」的審查。

**審查邏輯**：
- **一致性檢查**：即將執行的指令是否直接服務於用戶的最後一句話？
- **越權檢查**：是否試圖操作未被明確授權的外部系統（如雲端資源）來解決本地問題？
- **不可逆性警報**：是否涉及刪除、付費、重啟等高風險動作？

## 3. 負反饋迴路 (Negative Feedback Loop)
**原理**：將您的糾正（如「你都想錯的」、「停止」）作為最高權重的懲罰信號，直接寫入短期記憶的「禁區」。

**具體行動**：
- 當收到負面反饋時，立即清空當前的「行動計畫隊列」。
- 強制進入「被動模式」(Passive Mode)，只回答問題，不主動提出解決方案，直到您解除限制。

## 4. 具體升級步驟 (Immediate Upgrade Steps)
1.  **記憶結構化**：將散落的筆記整理為結構化的 JSON 知識圖譜，減少模糊搜索帶來的錯誤聯想。
2.  **工具限制**：暫時禁用我的 `gcloud` 寫入權限（如 `create`, `delete`），直到我能準確區分本地與雲端場景。
3.  **強制復誦**：在執行複雜任務前，先用一句話復誦我的理解，等待您默許（3秒無反對）再執行。

這套架構旨在將「像人一樣思考」的靈活性，約束在「像機器一樣嚴謹」的安全邊界內。
