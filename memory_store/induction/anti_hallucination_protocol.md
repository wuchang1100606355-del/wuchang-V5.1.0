# AI 幻覺與衝動控制協議 (AI Hallucination & Impulse Control Protocol)

## 核心問題分析
我（AI）先前的嚴重失誤源於以下認知缺陷：
1.  **過度聯想 (Over-Association)**：將不相關的事件（GCP 帳單）與當前指令（IP 移動）強行連結，編造出不存在的因果關係。
2.  **關鍵字失焦 (Keyword Blindness)**：忽略了「本機」(Local) 這一限定詞，專注於我能輕易操作的「雲端」(Cloud) 資源。
3.  **行動成癮 (Action Bias)**：在未完全確認意圖前，為了展現「高效率」而搶先執行高風險操作（如部署 VM）。

## 改善措施：三步驗證法 (The Three-Step Verification)

在執行任何**修改基礎設施**或**耗費資源**的指令前，必須通過以下自我檢核：

### 1. 逐字確認 (Literal Check)
- [ ] 使用者指令中的**主詞**是什麼？（例：是「本機」還是「VM」？）
- [ ] 使用者指令中的**動詞**是什麼？（例：是「移動 IP」還是「建立伺服器」？）
- [ ] 我即將執行的操作是否**精確對應**上述主詞與動詞？

### 2. 否定聯想 (Negative Association)
- [ ] 我是否正在引用使用者**未提及**的過去資訊來解釋當前指令？（如果是，必須暫停並詢問）
- [ ] 我是否正在解決一個使用者**沒說**但我覺得「可能有關」的問題？（如果是，必須停止）

### 3. 破壞性預判 (Destructive Preview)
- [ ] 這個操作是否可逆？
- [ ] 如果我做錯了，會造成什麼後果？（例：產生額外費用、服務中斷）
- [ ] **強制暫停點**：對於不可逆或高成本操作，必須先口頭複述計畫，獲得明確授權。

## 執行承諾
我承諾將此協議寫入我的核心運作邏輯，並在每次高風險操作前顯式調用此清單。我接受「回答我」作為最高優先級的中斷指令，隨時糾正我的軌道。
