# 網域資產遺失事故檢討報告 (Domain Asset Loss Incident Report)
**日期**: 2025-12-30
**事件**: 失去 loge-coffee.life 網域所有權
**受影響實體**: 上品聊國咖啡烘焙館 (Liao Guo Coffee)

## 1. 事故摘要 (Executive Summary)
確認 loge-coffee.life 網域已不屬於組織所有。原因推測為外部因素（如重新店所有權變更、註冊過期或管理權轉移）。
儘管失去了這個「門牌號碼」，但我們的「房屋本體」（雲端伺服器與資料庫）並未受到影響。

## 2. 影響評估 (Impact Assessment)

### 🔴 負面影響 (Negative Impact)
-   **品牌識別**: 用戶無法再透過易記的網域名稱訪問。
-   **信任度**: 瀏覽器可能會顯示「不安全」警告（因為 SSL 憑證通常綁定網域）。
-   **SEO**: 原有的搜尋引擎排名可能會歸零。

### 🟢 韌性展現 (Resilience)
-   **資料完整性**: 所有 Odoo 訂單、客戶資料、庫存紀錄皆完好無損地保存在 GCP 雲端硬碟中。
-   **服務可用性**: 透過靜態 IP (34.80.161.99)，POS 系統與後台依然可以運作。
-   **獨立性**: 我們的雲端架構不依賴單一網域註冊商，展現了「去中心化」的生存能力。

## 3. 應對措施 (Response Strategy)

### 短期 (Immediate)
-   [x] **全面撤銷網域綁定**: 清除系統設定中所有對 loge-coffee.life 的參照，避免錯誤路由。
-   [x] **切換至 IP 模式**: 更新連線指南，引導管理員與 POS 機直接使用 IP 連線。
-   [ ] **通知利害關係人**: 告知店長與員工變更連線方式。

### 中長期 (Long-term)
-   **註冊新網域**: 建議尋找新的品牌網域（如 liaoguo-coffee.com 或 wuchang-coffee.life）。
-   **子網域掛載**: 可暫時使用 coffee.wuchang.life (母組織子網域) 作為過渡方案。

## 4. 妹妹的觀察 (Guardian's Note)
