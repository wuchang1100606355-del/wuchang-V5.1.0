# 雲端與本地模組成本結構分析報告 (Cloud vs. Local Cost Structure & P&L Input)
**日期**: 2025-12-30
**分析目的**: 提供「五常社區服務系統」之損益模型推算基礎，釐清雲端與本地資源之使用比例與成本，並確立**公益資源合規使用與數位平權推動原則**。

## 1. 資源配置總覽 (Resource Overview)

系統目前採用 **「混合雲架構 (Hybrid Cloud)」**，核心運算位於 Google Cloud，邊緣運算與實體服務位於本地端。

| 模組類別 | 部署位置 | 核心組件 | 功能職掌 |
| :--- | :--- | :--- | :--- |
| **雲端模組** | Google Cloud (Asia-East1) | 2 VMs, Cloud Router, DNS | Odoo ERP, 資料庫, API 核心, 全域路由 |
| **本地模組** | 新北三重 (總店/協會) | 實體 POS 機, 辦公室 PC, 網路設備 | 前台收銀, 店內庫存管理, 現場行政 |

## 3. 使用比例分析 (Usage Ratio)

依據目前的架構與業務邏輯推算：

-   **運算負載 (Compute Load)**: **雲端 80% / 本地 20%**
-   **資料存儲 (Storage)**: **雲端 95% / 本地 5%**
-   **成本責任 (Cost Responsibility)**:
    -   **雲端**: 公共財 (Public Goods) -> **免費提供**。
    -   **本地**: 私有財 (Private Goods) -> **使用者付費**。

## 4. 成本分攤與贊助模型 (Cost Sharing & Sponsorship Model)

為解決「收費違規、不收費倒貼」的兩難，確立 **「分攤 + 贊助 (Sharing + Sponsorship)」** 雙軌制：

1.  **雲端資源零收費 (Zero Cloud Fee)**:
    -   嚴格禁止對 Google 捐贈的算力進行轉售或租賃。
    -   商家使用雲端 ERP/POS **不需支付軟體授權費或主機租金**。

2.  **本地成本分攤 (Local Cost Sharing)**:
    -   **性質**: 代墊款歸墊 (Reimbursement)。
    -   **項目**: 協會協助代管之硬體折舊、現場電力分攤、專線網路費。
    -   **機制**: 憑證實報實銷，或依比例計算之定額分攤金。

3.  **自由樂捐與企業贊助 (Donation & Sponsorship)**:
    -   **性質**: 贈與 (Gift)。
    -   **對象**: 針對協會提供的「技術支援服務」、「教育訓練」與「系統維護人力」。
    -   **精神**: 商家若認同系統帶來的效益，以 **「企業贊助款」** 回饋協會，支持社區數位平權計畫。

## 5. 公益資源利用率與分配分析 (Public Resource Utilization)

針對 **「重新總店」** 目前的資源佔用進行分析，重點在於 **「剩餘算力如何回饋公益與推動科技普及」**。

### 5.1 流量模型推算 (Traffic Model)
-   **每日訂單**: 200 筆 (高標估算)
-   **網站瀏覽**: 每日 500 次

### 5.2 資源消耗與剩餘算力 (Consumption & Surplus)

| 資源維度 | 預估消耗量 (重新店) | 伺服器總承載能力 | **公益可用剩餘算力** | 意義 |
| :--- | :--- | :--- | :--- | :--- |
| **運算 (CPU)** | < 2% | 100% (2 vCPU) | **> 98%** | **可供其他商家或 NPO 掛載網站** |
| **記憶體 (RAM)** | ~12% | 100% (4 GB) | **~88%** | **可供社區數據分析運算** |
| **網路流量** | < 0.1% | 100 GB/月 | **> 99%** | **可供開放資料 API 存取** |

### 5.3 資源共享策略 (Resource Sharing Strategy)
-   **數位平權 (Digital Equity)**: 剩餘算力應視為 **「降低數位落差的工具」**。
-   **科技普及 (Tech Popularization)**:
    1.  **商家數位化示範**: 重新店作為示範點，證明小店也能用低成本擁有現代化數位工具。
    2.  **友善組織託管**: 無償或低價協助其他在地 NPO 或微型商家架設形象網站。
    3.  **急難救助系統**: 在災難發生時，此伺服器可瞬間轉作資訊集散中心。
