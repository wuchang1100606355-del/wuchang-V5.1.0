================================================================================
外接硬碟虛擬記憶體自動設定 - 快速開始
================================================================================

🚀 執行方式（選擇其中一種）：

方法 1：雙擊執行 BAT 檔案（最簡單）
-----------------------------------
1. 找到檔案：scripts\RUN_AS_ADMIN_AND_RESTART.bat
2. 右鍵點擊 →「以系統管理員身分執行」
3. 確認 UAC 提示
4. 等待設定完成並自動重啟

方法 2：PowerShell 指令
-----------------------------------
以管理員身份開啟 PowerShell，執行：

cd "G:\共用雲端硬碟\五常雲端空間"
.\scripts\auto_setup_and_restart.ps1

方法 3：一行指令（自動提升權限）
-----------------------------------
在任何 PowerShell 視窗中執行：

Start-Process powershell -Verb RunAs -ArgumentList "-NoProfile -ExecutionPolicy Bypass -File `"G:\共用雲端硬碟\五常雲端空間\scripts\auto_setup_and_restart.ps1`""

================================================================================
⚠️ 重要提醒
================================================================================

1. ✅ 儲存所有工作
2. ✅ 關閉不必要的應用程式
3. ✅ 確認 E: 磁碟（外接硬碟）已連接
4. ✅ 腳本執行後會自動重新啟動電腦
5. ⚠️ 有 30 秒倒數時間可以取消（按 Ctrl+C）

================================================================================
📋 設定內容
================================================================================

- 目標磁碟：E:
- 初始大小：16 GB
- 最大大小：32 GB

================================================================================
✅ 重新啟動後驗證
================================================================================

電腦重新啟動後，執行以下指令驗證：

# 檢查分頁檔案
Get-CimInstance -ClassName Win32_PageFileUsage | Select-Object Name, AllocatedBaseSize

# 重新啟動 Ollama
docker restart wuchang-ollama-1

# 測試模型
docker exec wuchang-ollama-1 ollama run qwen2:7b "Hello"
