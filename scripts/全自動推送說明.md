## 📋 功能說明

本工具提供全自動無人值守的工作進度推送功能，使用最高授權（階段三權限解放），可究責對象無安全顧慮。

### 主要功能

1. **自動生成工作進度摘要**
   - 自動收集已完成的工作項目
   - 自動識別待處理項目
   - 自動生成詳細的工作進度報告

2. **安全推送機制**
   - 使用 `safe_sync_push.py` 進行安全推送
   - 遵循 `RISK_ACTION_SOP.md` 的安全規範
   - 推送前強制進行伺服器健康檢查
   - 所有操作記錄到稽核日誌

3. **最高授權運行**
   - 使用系統創辦人權限（階段三權限解放）
   - 可究責對象無安全顧慮
   - 全自動無人值守運行

## 🚀 使用方法

### 方法 1: 使用命令行參數

```bash
# 乾跑模式（僅檢查，不實際推送）
python auto_push_work_progress_to_server.py --dry-run

# 實際推送（需提供健康檢查 URL 和目標資料夾）
python auto_push_work_progress_to_server.py \
  --health-url "https://wuchang.life/health" \
  --copy-to "\\\\SERVER\\share\\wuchang"
```

### 方法 2: 使用環境變數

```bash
# 設定環境變數
$env:WUCHANG_HEALTH_URL="https://wuchang.life/health"
$env:WUCHANG_COPY_TO="\\\\SERVER\\share\\wuchang"

# 執行推送
python auto_push_work_progress_to_server.py
```

### 方法 3: 自訂推送檔案

```bash
python auto_push_work_progress_to_server.py \
  --health-url "https://wuchang.life/health" \
  --copy-to "\\\\SERVER\\share\\wuchang" \
  --files "工作進度摘要_伺服器接手_20260123.md" "其他報告.md"
```

3. **原子操作**
   - 使用原子覆蓋機制

## 🔍 故障排除

### 問題 1: 缺少必要參數

**錯誤訊息**: `缺少必要參數`

**解決方法**:
- 提供 `--health-url` 和 `--copy-to` 參數
- 或設定環境變數 `WUCHANG_HEALTH_URL` 和 `WUCHANG_COPY_TO`

### 問題 2: 伺服器無回應

**錯誤訊息**: `無回應/不可驗證`

**解決方法**:
- 檢查伺服器健康檢查端點是否正常
- 檢查網路連線
- 檢查防火牆規則

### 問題 3: 檔案不存在

**錯誤訊息**: `部分檔案不存在`

**解決方法**:
- 檢查檔案路徑是否正確
- 確認檔案是否已生成
- 使用 `--files` 參數指定存在的檔案

1. **伺服器健康檢查**: 推送前必須通過伺服器健康檢查，否則自動中止
