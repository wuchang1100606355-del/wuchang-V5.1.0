# 首頁圖片生成說明

## 功能說明

已建立 `generate_homepage_image.py` 工具，可根據合規資料自動生成首頁圖片。

## 使用方式

### 1. 設定 API Key

需要設定以下環境變數之一：
- `WUCHANG_LLM_API_KEY`（優先）
- `OPENAI_API_KEY`（備用）

**Windows PowerShell:**
```powershell
$env:WUCHANG_LLM_API_KEY = "your-api-key-here"
```

**Windows CMD:**
```cmd
set WUCHANG_LLM_API_KEY=your-api-key-here
```

**Linux/Mac:**
```bash
export WUCHANG_LLM_API_KEY=your-api-key-here
```

### 2. 執行生成

```bash
python generate_homepage_image.py
```

## 功能特點

### 自動額度管理
- 每日額度限制（預設 10 次，可透過 `WUCHANG_IMAGE_DAILY_LIMIT` 環境變數調整）
- 自動追蹤使用量
- 每日自動重置
- 使用歷史記錄（保留最近 100 筆）

### 智能提示詞生成
- 根據 `compliance_data.json` 自動生成提示詞
- 包含組織名稱、使命、核心價值等資訊
- 自動優化為適合首頁的專業圖片

### 圖片儲存
- 自動下載並儲存到 `static/images/` 目錄
- 檔案命名：`homepage_banner_YYYYMMDD_HHMMSS.png`
- 同時儲存圖片 URL 和提示詞資訊

## 配置選項

### 環境變數

| 變數名稱 | 說明 | 預設值 |
|---------|------|--------|
| `WUCHANG_LLM_API_KEY` | API Key（優先） | - |
| `OPENAI_API_KEY` | API Key（備用） | - |
| `WUCHANG_LLM_BASE_URL` | API 基礎 URL | `https://api.openai.com/v1` |
| `WUCHANG_IMAGE_MODEL` | 圖片生成模型 | `dall-e-3` |
| `WUCHANG_IMAGE_DAILY_LIMIT` | 每日額度限制 | `10` |

### 圖片參數

- **尺寸**: `1024x1024`（DALL-E 3 標準）
- **品質**: `standard`（可改為 `hd`）
- **風格**: `vivid`（可改為 `natural`）

## 使用量追蹤

使用量記錄在 `image_generation_usage.json`：

```json
{
  "last_reset_date": "2026-01-23",
  "daily_usage": 1,
  "total_usage": 1,
  "history": [
    {
      "timestamp": "2026-01-23T03:20:00",
      "prompt": "...",
      "image_file": "static/images/homepage_banner_20260123_032000.png",
      "image_url": "https://..."
    }
  ]
}
```

## 生成的圖片特點

根據合規資料，生成的圖片將包含：
- 現代化、專業的首頁橫幅設計
- 傳達社區發展和數位包容理念
- 溫暖、歡迎的氛圍
- 現代科技與傳統社區價值結合
- 適合非營利組織網站的專業外觀
- 暖色調、簡潔現代設計
- 無文字疊加，純圖片

## 注意事項

1. **API 費用**: 使用 OpenAI DALL-E 3 會產生費用
2. **每日額度**: 預設每日 10 次，可調整
3. **圖片版權**: 生成的圖片屬於使用者所有
4. **網路連線**: 需要網路連線以下載圖片

## 故障排除

### 問題：未設定 API Key
**解決方案**: 設定 `WUCHANG_LLM_API_KEY` 環境變數

### 問題：已達每日額度上限
**解決方案**: 
- 等待明日自動重置
- 或調整 `WUCHANG_IMAGE_DAILY_LIMIT` 環境變數

### 問題：網路錯誤
**解決方案**: 檢查網路連線和 API 服務狀態

### 問題：圖片下載失敗
**解決方案**: 圖片 URL 會儲存在 JSON 檔案中，可手動下載
