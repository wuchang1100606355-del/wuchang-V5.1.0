## 📝 後續建議

### 1. 資金缺口數據更新

目前資金缺口使用占位符「??? 元」，可以通過以下方式更新：

#### 方式一：手動更新 HTML
```html
<div id="funding-amount">500,000 元</div>
```

#### 方式二：通過 JavaScript 更新
在 `initFundingProgress()` 函數中設定：
```javascript
const totalNeeded = 1000000; // 總需求金額
const currentRaised = 500000; // 目前已籌集金額
const remaining = totalNeeded - currentRaised;
```

#### 方式三：從後端 API 獲取
```javascript
fetch('/api/funding-status')
    .then(response => response.json())
    .then(data => {
        document.getElementById('funding-amount').textContent = 
            data.remaining.toLocaleString('zh-TW') + ' 元';
    });
```

### 2. 進度條更新

進度條會根據 `totalNeeded` 和 `currentRaised` 自動計算百分比。需要更新這兩個值來顯示實際進度。

### 3. 目標日期調整

如果需要調整目標日期（非100天），可以修改：
```javascript
targetDate.setDate(today.getDate() + 100); // 改為其他天數
```

## 💡 使用說明

### 更新資金缺口金額

1. **簡單方式**：直接修改 HTML 中的 `funding-amount` 元素
2. **動態方式**：修改 `initFundingProgress()` 函數中的 `totalNeeded` 和 `currentRaised` 變數
3. **API 方式**：建立後端 API 端點，從資料庫獲取實際資金數據

### 調整倒數天數

修改 JavaScript 中的：
```javascript
targetDate.setDate(today.getDate() + 100); // 改為其他天數
```

### 自訂進度條

進度條會根據已籌集金額和總需求金額自動計算。確保 `totalNeeded` 和 `currentRaised` 的值正確即可。
