# 透過 Odoo UI 手動納管設備

當 API 無法訪問時，可以透過 Odoo 管理界面手動納管設備。

## 步驟

1. **登入 Odoo**
   - 訪問: `http://192.168.50.249:8069/web/login` (VM 為本地機器)
   - 使用管理員帳號登入

2. **進入設備管理**
   - 點擊「應用程式」選單
   - 找到「Wuchang Core」→「基礎設施」→「設備」

3. **建立新設備**
   - 點擊「建立」按鈕
   - 填寫以下資訊：
     - **名稱**: `v3_mix_edla_gl`
     - **IP 地址**: `192.168.50.86`
     - **MAC 地址**: (可選，如果知道)
     - **設備類型**: `POS Terminal`
     - **狀態**: `Online`
     - **備註**: 
       ```
       Android 13 POS 設備
       IP: 192.168.50.86:41895
       開發者模式: 已開啟
       USB/GPU/WiFi 偵錯: 已開啟
       納管時間: 2025-01-07
       ```

4. **儲存設備記錄**
   - 點擊「儲存」按鈕
   - 確認設備已建立

5. **後續設定**
   - 在 Google Workspace Admin Console 註冊設備
   - 設定 Kiosk 模式
   - 配置應用程式和安全策略
