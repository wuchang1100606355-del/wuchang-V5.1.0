# 網絡共享設定指南

**執行時間**: 2026-01-12  
**系統版本**: Wuchang OS V5.1.0  

---

## 📋 問題說明

執行最優同步時，發現網絡共享路徑不存在。需要先在 UI 筆電上設定網絡共享。

---

## 🔧 設定網絡共享

### 方式 1: 在 UI 筆電上設定共享資料夾

#### 步驟 1: 建立共享資料夾

1. 在 UI 筆電上建立資料夾（例如：`C:\wuchang`）
2. 右鍵點擊資料夾 → **內容** → **共用** 標籤
3. 點擊 **共用** 按鈕
4. 選擇要共用的使用者（例如：`Everyone` 或特定使用者）
5. 設定權限為 **讀取/寫入**
6. 點擊 **共用**

#### 步驟 2: 進階共用設定

1. 在資料夾內容視窗中，點擊 **進階共用**
2. 勾選 **共用此資料夾**
3. 設定共用名稱（例如：`wuchang`）
4. 點擊 **權限**
5. 設定權限（建議：完全控制）
6. 點擊 **確定**

#### 步驟 3: 網路探索

1. 開啟 **控制台** → **網路和網際網路** → **網路和共用中心**
2. 點擊 **變更進階共用設定**
3. 啟用以下項目：
   - **網路探索**
   - **檔案及印表機共用**
   - **共用資料夾**
4. 點擊 **儲存變更**

### 方式 2: 使用 PowerShell 設定（自動化）

在 UI 筆電上執行以下 PowerShell 指令：

```powershell
# 建立資料夾（如果不存在）
$sharePath = "C:\wuchang"
if (-not (Test-Path $sharePath)) {
    New-Item -ItemType Directory -Path $sharePath -Force
}

# 設定共享
$shareName = "wuchang"
New-SmbShare -Name $shareName -Path $sharePath -FullAccess "Everyone"

# 確認共享
Get-SmbShare -Name $shareName
```

## 🔍 驗證共享設定

### 方式 1: 在本機電腦上測試

```powershell
# 測試共享路徑
Test-Path "\\192.168.50.84\wuchang"

# 列出共享
Get-SmbShare -CimSession "192.168.50.84"
```

### 方式 2: 使用檔案總管

1. 開啟檔案總管
2. 在地址列輸入：`\\192.168.50.84`
3. 應該可以看到共享資料夾（`wuchang`）

---

## 🚀 設定完成後執行同步

共享設定完成後，可以使用以下方式執行最優同步：

```powershell
# 預覽模式
.\scripts\optimal_sync.ps1 -DryRun

# 實際同步
.\scripts\optimal_sync.ps1 -DryRun:$false

# 或指定路徑
.\scripts\optimal_sync.ps1 -RemotePath "\\192.168.50.84\wuchang" -DryRun:$false
```

## ⚠️ 常見問題

### 問題 1: 無法存取共享

**解決方法**:
1. 確認防火牆允許檔案共用
2. 確認網路探索已啟用
3. 確認使用者權限設定正確

### 問題 2: 權限不足

**解決方法**:
1. 確認共享權限設定為「完全控制」
2. 確認資料夾權限允許存取
3. 使用管理員權限執行

### 問題 3: 找不到共享

**解決方法**:
1. 確認 IP 地址正確
2. 確認設備在線
3. 使用 `Test-Connection` 測試連接性

## 💡 替代方案

如果無法設定網絡共享，可以使用以下替代方案：

### 方案 1: 使用 SSH/SCP

```powershell
# 使用 SCP 傳輸檔案
scp -r user@192.168.50.84:/path/to/wuchang C:\wuchang
```

### 方案 2: 使用 USB 隨身碟

1. 在 UI 筆電上複製檔案到 USB 隨身碟
2. 在本機電腦上從 USB 隨身碟複製檔案
3. 使用比較工具手動同步

### 方案 3: 使用雲端同步

1. 使用 Google Drive、OneDrive 等雲端服務
2. 在兩個設備上同步相同資料夾
3. 使用比較工具比較差異
