# Wuchang Community Frontend (V5.1.0)

## Overview
This is the modern React-based frontend for the Wuchang Community Service System. It implements the "Realistic Public Welfare" design style and unifies the user interface.

## Tech Stack
-   **Framework**: React 18
-   **Build Tool**: Vite
-   **Styling**: Tailwind CSS 3
-   **Icons**: Lucide React
-   **Routing**: React Router DOM

## Directory Structure
-   `src/`: Source code
    -   `components/`: Reusable components (Navbar, Footer, LittleJChat)
    -   `pages/`: Page views (Homepage)
    -   `App.tsx`: Main router configuration
    -   `main.tsx`: Entry point
-   `public/`: Static assets
-   `index.html`: Entry HTML

## Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Key Features
-   **Homepage**: Features the "Little J" narrative and public welfare appeal.
-   **Little J Chat**: Interactive component for residents to share dreams with the AI.
-   **Design System**: Earth tones and realistic imagery to convey warmth and trust.
