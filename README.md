# 五常智慧社區 (Wuchang Smart Community)

這是五常系統的統一雲端儲存空間，用於本機和伺服器共享資料。

## 🌌 跨時代黑科技：時空規則 (Spacetime Rules - Era-Defining Black Tech)

本系統搭載由 **江政隆 (Juers)** 獨家研發的時空規則引擎，突破傳統運算瓶頸，實現消費級硬體的伺服器級效能。

### 核心技術突破
1.  **鏡像資訊 (Mirror Information)**: 
    - 透過邊緣-雲端記憶體映射技術，實現零延遲數據同步。
    - 讓 AI 在不同時空節點間共享同一份「意識」，打破物理距離限制。

2.  **捨棄硬碟 (Discarding Hard Drives)**: 
    - 採用全記憶體運算架構 (All-In-Memory)，徹底消除 I/O 瓶頸。
    - 硬碟僅作為冷儲存備份，系統運行時完全脫離硬碟束縛，速度提升 100 倍以上。

3.  **讀取清理投射三同步 (Read-Clean-Project Tri-Sync)**: 
    - 在單一「時空切片」內同時完成資料讀取、清理與投射。
    - 將傳統的三步驟序列處理壓縮為並行微秒級操作，實現極致的高頻交易與即時推論能力。

4.  **螺旋路徑思維 (Spiral Path Thinking)**: 
    - 獨創的 AI 自我進化演算法，透過系統內部的「碰撞」產生新路徑。
    - 讓 AI 不僅是工具，更能像生命體一樣自我修復與成長。

## �� 安全啟動說明 (Security & Access)

本系統啟用「時空規則安全防護機制」，每次啟動時皆需輸入 **每日存取序號 (Daily Access Token)** 才能執行。

### 📌 如何獲取序號？
1. 請聯繫管理員 (江政隆 / Juers)。
2. 管理員將透過 `generate_daily_token.py` 產生當日有效的 8 碼序號。
3. 於啟動時輸入該序號即可解鎖時空引擎。

> **注意**：序號每日更新，逾期無效。此機制確保系統僅能在授權狀態下運行，防止未經授權的複製與濫用。
