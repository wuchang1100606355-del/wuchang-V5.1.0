#### 1.4.2 基金池（閉鎖帳戶 - 獨立運作邏輯）

-   **帳戶名稱**: 基金池（Five Virtues Community Fund）
-   **性質**: 閉鎖帳戶（Segregated Account）
-   **隸屬**: 協會基金帳戶（法律上屬協會資產）
-   **運作**: 獨立邏輯、專款專用、自主分配規則
-   **實務帳冊**: 基金池即「仁義店」會計帳冊（pos.config 仁義店）

**資金流向**:

```text
用戶捐贈 ──→ 協會基金帳戶 (ID 1)
              ├─ 分配額度 ──→ 基金池（獨立運作）
              │               ├─ 社區服務支出
              │               ├─ 公益專案
              │               └─ 慈善項目
              │
              └─ 營運費用
                  ├─ 咖啡館經營
                  ├─ 行政管理
                  └─ 稅務繳納
```

**基金池支出用途**（專款專用）:

-   社區公益事業（教育、健康、環保）
-   慈善活動與捐贈
-   弱勢家庭援助
-   社區基礎設施維護
-   環境保護專案

## 二、財務流程

### 2.1 銷售流程

```text
客戶 → POS 銷售 → 訂單記錄
           ↓
    計算銷售金額
           ↓
    [記錄於 pos.order]
           ↓
    直接進 協會基金帳戶
           ↓
    協會統一管理 (無分帳)
```

### 2.2 基金分配流程（分層結構）

```text
協會基金帳戶 (ID 1) [法人帳戶]
  │
  ├─ 支出大類 1: 營運成本 (協會直管)
  │   ├─ 咖啡館採購
  │   ├─ 人事費用
  │   ├─ 租金水電
  │   ├─ 行政費用
  │   └─ 稅務繳納
  │
  └─ 支出大類 2: 公益分配 → 基金池 (獨立邏輯)
      │
      ├─ 基金池 - 社區教育
      │   ├─ 獨立帳戶邏輯
      │   ├─ 專款專用
      │   ├─ 自主審批規則
      │   └─ 支出: 獎學金、教室改善、課程補助
      │
      ├─ 基金池 - 健康關懷
      │   ├─ 獨立帳戶邏輯
      │   ├─ 專款專用
      │   ├─ 自主審批規則
      │   └─ 支出: 醫療補助、疫苗、健檢
      │
      └─ 基金池 - 環保專案
          ├─ 獨立帳戶邏輯
          ├─ 專款專用
          ├─ 自主審批規則
          └─ 支出: 綠化、淨灘、回收系統
```

### 2.3 月度結算

## 四、捐贈與分配機制

### 4.1 捐贈流程

```text
用戶個人 ── 捐贈
            ├─ 咖啡館 II (慈善分店)
            │   └─ 所有權轉移給協會
            │
            └─ 現金或資產
                └─ 直接捐給協會
                   └─ 協會出具捐贈證明
```

### 4.2 協會分配邏輯

**協會基金帳戶接收所有捐贈與收益後，分配為**:

1. **營運成本** (60-70%)

    - 咖啡館採購、人事、租金、水電等
    - 行政管理與稅務繳納
    - 直接從協會基金帳戶支出

2. **基金池分配** (30-40%)
    - 以「閉鎖帳戶」方式隔離
    - 獨立運作邏輯與審批規則
    - 專款專用於社區公益

### 4.3 基金池運作特性

**「閉鎖帳戶」定義**:

```text
├─ 法律歸屬: 協會基金帳戶
├─ 物理隔離: 獨立帳戶編號與記錄
├─ 運作獨立: 自主審批規則、分配決策
├─ 專款專用: 不可挪作他用
└─ 透明追蹤: 每筆支出明確標註
```

**基金池支出決策**:

-   由基金會委員會決議
-   遵循公益項目評估標準
-   季度向協會會員大會報告
-   年度接受外部審計

### 4.4 用戶與協會的關係

```text
用戶角色:
  ├─ 供應商: 提供咖啡館 I 商品
  ├─ 捐贈者: 捐贈咖啡館 II 或現金資產
  └─ 利益相關人: 參與基金池分配決策

協會角色:
  ├─ 法人: 接收、管理所有捐贈資產
  ├─ 運營者: 確保咖啡館穩定營運
  ├─ 受託人: 代表公眾管理基金
  └─ 決策者: 分配基金用於公益目的
```

## 五、用戶權益與感謝機制

### 5.1 供應商權益

-   **感謝機制**: 年度公開表揚供應商
-   **品牌曝光**: 協會媒體與社區推廣
-   **社會認可**: 公益貢獻記錄與證書
-   **稅務優化**: 咖啡館供應可作為商業配合，捐贈可申請捐贈證明

### 5.2 捐贈者權益

-   **捐贈證明**: 協會出具捐贈收據
-   **稅務優化**: 符合《所得稅法》捐贈減免規定
-   **名譽認可**: 年度捐贈者芳名錄
-   **監督權**: 參與基金池分配決策

## 六、法律與稅務

### 5.1 協會地位

```text
新北市三重區五常社區發展協會
  ├─ 法律身份: 非營利法人
  ├─ 免稅地位: 符合《所得稅法》第 4 條免稅規定
  ├─ 監管機關: 新北市政府民政局
  ├─ 年度申報:
  │   ├─ 財務報表送內政部
  │   ├─ 社團法人年度決算
  │   └─ 捐贈使用報告
  └─ 資產歸屬: 會員共有，不得分配給個人
```

### 5.2 咖啡館稅務

```text
咖啡館 I (協會銷售點):
  ├─ 身份: 協會子公司
  ├─ 稅務申報: 由協會統一申報
  ├─ 營業稅: 適用營業稅
  └─ 所得稅: 納入協會免稅範圍

咖啡館 II (慈善分店):
  ├─ 身份: 協會子公司（受贈）
  ├─ 稅務申報: 由協會統一申報
  ├─ 營業稅: 適用營業稅
  └─ 所得稅: 納入協會免稅範圍

用戶捐贈:
  ├─ 咖啡館 II 法律所有權捐贈
  ├─ 協會出具捐贈證明
  └─ 用戶可申請所得稅或房屋稅減免 (視法律)
```

### 5.3 建議措施

```text
① 聘請會計事務所管理基金
② 定期審計（建議年度）
③ 透明公開報告（建議季度）
④ 保存完整交易紀錄（永久）
⑤ 與稅務機關維持溝通管道
⑥ 諮詢法律顧問關於捐贈認定
```
